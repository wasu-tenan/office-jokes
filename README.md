One line about office life, under 200 characters — the funniest line wins in
head-to-head judging by an AI judge.

Entry for the [Make the AI Judge Laugh: Office Jokes](https://make.fun/bounty/u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a) bounty on [make.fun](https://make.fun/r/2mmz0hmg).

## How it works

`main.py` (Python 3.13, standard library only) writes a single one-line
office joke to `/output/entry.txt`. The program is fully deterministic: it
writes the same bytes on every run.

## Run it

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt`. A custom output location can be
given with `--output <path>` or the `MAKEFUN_OUTPUT_DIR` environment variable.

## The joke

> I asked my calendar for focus time, so it booked a meeting called "Focus Time" with twelve people and no agenda.
